# Practical AI Course

An independent curriculum for learning and teaching AI tools, daily work, n8n automation, and website building. The course includes 40 lessons with speaking notes, demos, exercises, and answer checks. Nine n8n project blueprints and a website with a document FAQ assistant give you practice building with sample data.

## Start here

- [Read the complete course in one Markdown file](Practical-AI-Course-Guide.md). Attach this file to an AI assistant that accepts Markdown.
- [Open the modular agent skill](teach-practical-ai/SKILL.md). Give the entire skill folder to an agent that can read project files so it can open the chapter and examples it needs.
- [Browse the lesson index](teach-practical-ai/references/source-map.md) or [pick an n8n project](teach-practical-ai/references/n8n-projects.md).

## Use it with an AI agent

For instructor materials, attach the full guide or give the agent access to this repository, then ask:

> Use the Practical AI Course to prepare lesson F01 for me to teach. Include a talk track, a live demo, an exercise, and a separate answer key.

To build a workflow with the included data, ask:

> Use the P03 email assistant blueprint. Build it with the provided mock emails and show which drafts, review items, and duplicates the workflow produces.

The [instructor playbook](teach-practical-ai/references/instructor-playbook.md) has suggested session plans and a grading rubric. The [practice kit](teach-practical-ai/references/practice-kit.md) contains fictional examples and expected results.
